# Outreach Discovery Sources

Date: 2026-07-05

Use this note when expanding beyond the current LinkedIn feed sample.

## Source Classes

- LinkedIn feed and profile posts
- ATS job boards: Ashby, Lever, Greenhouse
- Company blogs and hiring pages
- Substack and Medium posts
- Public publications and journal articles

## What To Capture

- `source_type`
- `source_title`
- `source_url`
- `person_or_company`
- `contact_route`
- `best_channel`
- `fit_note`
- `next_action`

## Routing Reminder

- 1st-degree or active thread: protected relationship; draft a DM, then require exact current-chat approval before sending
- 2nd/3rd-degree: note-style connection request
- No default InMail
- Draft first, send only after approval

## Logging

- Record live outbound touches in `data/outreach/log.md`
- Record route discoveries in the appropriate TSV before sending
- Keep public-writing leads and job-board leads separate so future agents can sort them quickly
