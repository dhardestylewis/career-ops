# Archive Note

This repository is a durable career-ops workspace for job search, outreach, and application workflow automation.

## Read First

- `CLAUDE.md`
- `AGENTS.md`
- `docs/CODEX.md`
- `data/outreach-operator-card.md`
- `data/outreach-contact-dossier.md`
- `data/outreach-log.md`

## Canonical Workflow

- Use the operator card as the run sheet.
- Treat the live outreach log as the source of truth for sent state.
- Use the dossier and queue for planning, not as a second ledger.
- Preserve Chrome handoff tabs when they are authenticated, but do not assume login state survives a new session.

## What to Ignore

- Old outreach branches that are already merged or superseded.
- Draft-only copies that are explicitly marked as mirrors or cleanup lanes.
- Unrelated backup files, temporary exports, and scratch artifacts.

## Current Intent

- Keep the outreach workflow safe, repeatable, and deduplicated.
- Keep future agents aligned on SPC gating, reply routing, and immediate logging.
- Leave one canonical path for drafting, sending, and follow-up.
