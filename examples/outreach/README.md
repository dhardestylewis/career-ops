# Outreach Route Example

This directory contains sanitized examples that mirror the structure of local outreach routing data without exposing private contacts, live URLs, or send history.

Rules for public examples:

- Use placeholder names only.
- Use fake URLs and fake email addresses.
- Do not copy any private user-layer file contents into GitHub.
- Keep the real route discovery data in local workspace files only.

Example files here are safe to reference in docs, tests, and PRs.
